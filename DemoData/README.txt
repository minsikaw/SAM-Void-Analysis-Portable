SYNTHETIC DATA ONLY - NOT AN ACOUSTIC MEASUREMENT

Import this folder with "Import images" to demonstrate identity/mask matching.
Both samples have deliberately fabricated image structures and binary masks.
Automatic detector accuracy on these images is NOT guaranteed, since the original
algorithm was developed for SAM C-scans. If the detector misses the ROI, choose
"Review selected" and draw a manual die rectangle before quantifying.

The high-intensity defect regions were added to mimic mask overlays for testing.
These samples are not proof of reliable physical delamination detection.
